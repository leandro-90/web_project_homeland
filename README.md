# Tripleten web_project_homeland

Projeto proposto pela TripleTen, com o objetivo de praticar e aprender desenvolvimento web responsivo, baseados em telas maiores, como de 1024px á 2350px. Também para telas menores que se encaixam na categoria mobile como tablet e smartphones.

Tal projeto envolve as seguintes tecnologias:

- HTML5 e CSS3

Site: https://leandro-90.github.io/web_project_homeland/
